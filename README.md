# Tech Debt Radar

Visualize and prioritize technical debt across your codebase with a scored, interactive radar. Identify hotspots, track remediation progress and turn "we should fix that someday" into a ranked action plan.

**Live app:** https://zion-support.github.io/tech-debt-radar/

## Features
- Scored debt categories: code quality, architecture, tests, docs, security, dependencies
- Visual radar chart to spot imbalances at a glance
- Prioritization by impact vs effort so teams fix what matters first
- Exportable report for engineering leadership
